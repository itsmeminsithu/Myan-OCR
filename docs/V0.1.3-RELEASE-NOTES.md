# Myan OCR v0.1.3 — Release notes

## Security and reliability

Local Docker launch is unchanged (`./scripts/start-mac.sh`, http://localhost:8388). The Compose file explicitly uses local-development authentication bypass and binds the published port to 127.0.0.1. Do not publish it on a public host with this setting.

Public deployments require `MYAN_OCR_LOCAL_DEV=0`, a strong `MYAN_OCR_API_KEY`, a valid `MYAN_OCR_ALLOWED_HOSTS` allowlist and a trusted authenticated reverse proxy/server-side session layer. The bundled browser JavaScript must never contain this key.

OCR processing uses a cooperative deadline (default 75 seconds) and a 20-million-pixel total PDF raster budget. Docker is limited to 1 GiB RAM, two CPU cores and 128 PIDs. Native PDF rendering cannot be forcibly interrupted in all cases.

## Google Vision / Google Translation

`GOOGLE_CLOUD_API_KEY` only signals that credentials were provided. It does not prove Billing, Vision API permission, Translation API permission or model recognition quality. OCR and translation actions remain opt-in. Provider error responses are sanitized, and malformed response envelopes are rejected with controlled errors. No paid/live API calls were made in the release tests.

## Tests / limitations

Run `python -m pytest -q` (or `pytest -q` with included pytest.ini). Automated tests cover validation and mocked external services. Real Google API, Docker build, physical Safari/Android camera and public production reverse proxy have not been validated. Myanmar OCR cannot be guaranteed 100% accurate; users should review recognized text.
