# Myan OCR v0.1.2 — Release Notes

Developed by Min SiThu.

## Changes
- `/api/pdf`: up to eight pages, 12 MB file size, bounded raster dimensions. Page-level text returned.
- `/api/batch`: up to four images, 12 MB combined. Combined editable result returned.
- Web: separate PDF / multi-image selectors and optional browser-local text history.
- Rate-limit bucket cap, origin checks and local-only default authentication rule.

## Verified
- `python -m pytest -q`: 35 tests passed in the test environment.
- JavaScript syntax: `node --check web/app.js` passed.
- Synthetic Burmese OCR: 5.71% CER, 0/1 exact matches. No improvement demonstrated on this sample.
- PDF rasterization and PDF/batch API flows were tested using generated sample files and mocked recognition functions.

## Not verified
- Mac Docker production build and real Safari/iOS camera flows.
- Live Google Cloud OCR and Google Cloud/Ollama translation.
- Real multi-page Myanmar PDF recognition accuracy.
- Public internet security testing or distributed rate limits.

## Constraints
- All image/PDF content is processed in server memory; no backend history DB.
- Browser history saves text only when the user explicitly clicks Save.
- Do not put this developer version on a public server without authentication, reverse proxy controls, TLS and access management.
- PDF OCR is raster-based and can be slow; 8-page maximum is not a performance guarantee.
- 100% exact Myanmar OCR recognition cannot be promised.
